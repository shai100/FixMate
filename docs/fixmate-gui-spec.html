GUI Design Specification — Web & Mobile

Version 1.0 · June 2026 · Covers: Technician Mobile App (dark) + Admin/Curator Web Console (light) · All illustrations rendered live in this document

1.Design Principles

Every visual decision serves a technician standing in front of a broken machine.

PrincipleImplication
Glanceable in sunlight & basementsHigh-contrast dark theme on mobile (OLED-friendly), minimum 13px body text, strong color coding for status
Gloves-firstTouch targets ≥ 48×48px, generous spacing, voice input always one tap away, no hover-dependent actions on mobile
Safety is loudestSafety warnings use the only red banner in the system, always positioned above repair steps, never collapsible
Trust through provenanceEvery claim shows its source chip (manual page or field-verified badge); confidence badge tops every answer
Two products, one familyMobile app = dark, focused, single-column. Web console = light, dense, data-oriented. Shared palette, type, radii, and components

Rules: semantic red is only for safety/danger states. Equipment profiles get an accent color from an 8-color set (sky #38BDF8, orange #FB923C, violet #A78BFA, teal #2DD4BF, rose #FB7185, lime #A3E635, amber #FBBF24, indigo #818CF8) used for icons, active tabs, and step numbers — never for text bodies. All text/background pairs meet WCAG 2.1 AA (≥4.5:1).

Inter (UI, Latin) + Noto Sans Hebrew (Hebrew, auto-fallback in the same stack) + JetBrains Mono (error codes, part numbers, values). Variable fonts, self-hosted. Hebrew text triggers full RTL mirroring (§8).

8.RTL, Localization & Accessibility

AreaSpecification
RTL (Hebrew)Full mirror via CSS logical properties (margin-inline-start etc.): navigation, chat bubbles, step numbers, and chevrons flip; numerals, error codes, and part numbers remain LTR islands (dir="ltr" spans). Per-message direction auto-detected — mixed-language chats are supported.
Type in HebrewNoto Sans Hebrew, +1px size compensation at body sizes for x-height parity with Inter
ContrastWCAG 2.1 AA minimum on all pairs; safety banner red tested at 5.2:1 on Night background
Touch & motor48px targets, no long-press-only actions, text scaling to 130% without layout break
Screen readersAnswers as semantic ordered lists; confidence and safety announced before steps; figure images carry the extracted caption as alt text
Color independenceConfidence and curation states always pair color with icon + label — never color alone
